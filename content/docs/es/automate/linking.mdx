# Linking

La pestaña Linking empareja un anuncio de Depop con su equivalente
de Vinted para que el resto de SaleLinx sepa que son el mismo
artículo. Un crosslist con éxito establece el enlace
automáticamente; la pestaña Linking es para el caso en que
crosslistaste manualmente fuera de SaleLinx o perdiste un enlace.

<Callout>
Traducción completa al español próximamente. Consulta la
[versión en inglés](/en/docs/automate/linking) para el picker a
dos columnas, el fuzzy-match (Dice + Jaro-Winkler + bonus de
precio), las bandas de puntuación (Good / Maybe / Weak), el botón
Link 100&#37;, el unlinking y los planes que lo incluyen.
