# Shop Designer

Shop Designer es una herramienta visual de maquetación para tu
tienda Depop. Te permite fijar, reordenar y agrupar tus anuncios
activos sin arrastrar elementos en la UI de Depop, que es engorrosa
en la web y lenta en el móvil.

Esta función es **solo Depop**.
