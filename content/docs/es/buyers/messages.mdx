# Mensajes

La pestaña **Mensajes** fusiona los mensajes no leídos de Depop y
Vinted en una vista de dos columnas. Cada tarjeta muestra el
avatar del comprador, el usuario, el tiempo transcurrido desde su
último mensaje, una vista previa de dos líneas, el badge de no
leído y una miniatura del artículo en cuestión.
