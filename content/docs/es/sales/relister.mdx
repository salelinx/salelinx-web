# Republicador

El republicador elimina un anuncio antiguo y publica una copia nueva con el
mismo contenido, modificando ligeramente las fotos para que la detección
anti-duplicados de las marketplaces no lo marque. Resultado: tu artículo
recibe una fecha de publicación fresca y reaparece en el feed de búsqueda.
