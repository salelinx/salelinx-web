# Reposicionador

El reposicionador mantiene tu stock coherente entre marketplaces. Cubre dos
escenarios: vendedor de Vinted con varias unidades (republica tras cada
venta hasta agotar el stock) y artículos vinculados cross-plataforma
(desactiva el otro lado cuando se vende).
