# Installing the SaleLinx extension

SaleLinx runs entirely inside your browser. Install it once, pin it to your
toolbar, and sign in with the same account you use for billing.

You&rsquo;ll need Google Chrome or any Chromium browser (Edge, Brave, Arc) and
a SaleLinx account.

## 1. Install from the Chrome Web Store

Open the [SaleLinx listing](https://chromewebstore.google.com/detail/salelinx/oichfmfogobecihmhlgkfcfbdceomenj) in the Chrome Web Store and click **Add to Chrome**.
Chrome will ask you to confirm the permissions the extension needs. Click
**Add extension** to continue.

<Callout variant="tip" title="What the permissions mean">
SaleLinx asks for access to depop.com and vinted.com so it can read your own
listings and fill in forms on your behalf. It does not run on any other site.
</Callout>

## 2. Pin the extension

After install, Chrome hides new extensions behind the puzzle icon in the
toolbar. Pin SaleLinx so you can reach it with one click.

<InstallPinCallout />

## 3. Sign in

Click the pinned SaleLinx icon to open the side panel. Sign in with the email
and password you used when you signed up on salelinx.com. If you haven&rsquo;t
signed up yet, use the **Create account** link at the bottom of the panel.

<Callout>
Billing and extension use the same account. If you reset your password on
the website, use the new password here too.
</Callout>

## 4. Your first run

Navigate to [depop.com](https://www.depop.com) or [vinted.com](https://www.vinted.com).
The SaleLinx panel opens automatically on product and profile pages. You&rsquo;ll
see a short checklist for linking your marketplace accounts, importing your
listings, and running your first crosslist.

## Troubleshooting

If something goes wrong, the [FAQ](/faq#troubleshooting) has quick fixes for
the most common install-time issues (panel not appearing, Chrome blocking the
install, signed in on the wrong account).
