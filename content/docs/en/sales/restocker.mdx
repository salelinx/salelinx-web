# Restocker

The restocker keeps your stock honest across marketplaces. Two scenarios it
handles:

1. **Multi-quantity Vinted seller.** You list a t-shirt with 3 in stock. As
   each one sells, the restocker reposts a fresh listing for the next unit
   so the item stays continuously listed without you doing anything.
2. **Cross-platform linked items.** Same item listed on both Depop and
   Vinted. When it sells on Depop, the restocker takes the Vinted copy down
   so you don&rsquo;t oversell. (And vice versa.)

## Where it lives

The **Restocker** tab in the panel. Each tracked item is one row.

## Adding an item

From the **Listings** tab, find the row, set **Restock = on**, and enter the
quantity you have in stock. (A quantity of 1 still counts &mdash; that&rsquo;s
the cross-platform single-unit flow.)

The Restock toggle and Qty number live inline on each Listings row, so you
can set up multiple items without leaving the dashboard.

## How it works (Vinted multi-quantity)

When you have N units tracked:

1. The marketplace listing sells. Vinted marks it sold.
2. The restocker checks (next scan tick) and confirms the item is closed
   using a live API check, not just a cached state.
3. It reposts a fresh copy of the same listing &mdash; same title,
   description, photos, price, mapped fields.
4. Quantity decrements by 1 in your SaleLinx record.
5. When quantity reaches 0, restock auto-disables for that item.

Reposts use the cloud-stored copy of the listing (title, description,
photos, mapped fields) so nothing is lost even if the marketplace removes the
old listing.

## How it works (cross-platform)

When you have an item linked across Depop and Vinted (typically because you
crosslisted it):

1. The item sells on one marketplace.
2. The restocker takes the other side down so you can&rsquo;t accidentally
   sell the same physical unit twice.
3. If you have remaining stock (quantity &gt; 1 across both sides), it then
   reposts the listing on whichever side is configured.

Account linking is what powers the &ldquo;these are the same physical item&rdquo;
relationship. See the [linking page](/docs/listings/manage-inventory#restocker-columns)
for the row-level toggles.

## Schedule

The restocker runs as part of the panel&rsquo;s background bot loop while
the panel is open. It uses safe pacing between checks and reposts so the
marketplaces don&rsquo;t flag the burst as automated activity.

## What it won&rsquo;t do

- **Won&rsquo;t restock without a verified sold signal.** A 404 from
  Vinted&rsquo;s API alone isn&rsquo;t enough &mdash; the restocker can
  also see the item just hasn&rsquo;t been indexed yet, and waits.
- **Won&rsquo;t loop on stale state.** If a previous run incorrectly marked
  an active listing as sold, the next run notices the live signal and
  corrects the cloud record back without reposting.
- **Doesn&rsquo;t modify photos.** If you want each repost to look fresh
  (different photo crop, different first image), use the [relister](/docs/sales/relister)
  instead &mdash; it&rsquo;s designed for that.

## Plan and access

Restocker is **Business only**. Pro doesn&rsquo;t include it.
