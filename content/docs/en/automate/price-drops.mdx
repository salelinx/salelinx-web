# Price Drops

Price Drops (also called auto-markdown) reduces prices on listings
you&rsquo;ve opted in, on a cadence you set per item. Each drop
bumps the listing&rsquo;s edit timestamp, which puts it back in the
relevant feeds. It also turns slow-moving inventory over without you
having to remember to revisit it.

## How the maths works

Drops are **cumulative**, not compounding. Cycle N targets:

```
new_price = original_price × (1 − N × percent / 100)
```

So at 10% per cycle, an item priced at £30 drops:

- Cycle 1: £30 &rarr; £27 (10% off original)
- Cycle 2: £27 &rarr; £24 (20% off original)
- Cycle 3: £24 &rarr; £21 (30% off original)
- ...

The percentage is always &ldquo;N% of the original price&rdquo;,
never of the current price. That means the per-cycle pound amount
stays constant rather than shrinking each round.

When the cumulative percent reaches 100%, drops stop. You can set a
**minimum price** floor so the item never drops below a number you
choose.

## Setting it up

In the **Price Drops** tab:

1. Pick listings to track. Select rows in the &ldquo;Available&rdquo;
   grid and click **Add selected**. They move to the
   &ldquo;Tracked&rdquo; grid.
2. Per tracked item, set:
   - **Percent per cycle** - 1 to 90.
   - **Interval (days)** - 1 to 180. Also the minimum age before the
     first drop fires.
   - **Minimum price** (optional) - hard floor.
   - **Start from** - original-listing age, or now (resets the
     clock).
3. Toggle **Enable auto-markdown** at the top of the tab. The
   scheduler starts running.

You can edit any item&rsquo;s settings later by clicking it in the
tracked grid.

## When drops fire

The scheduler runs on a 12, 24 or 48 hour alarm (your choice). On
each tick it asks Depop and Vinted for the current state of every
tracked item, then for each:

- Skip if item is sold or hidden.
- Skip if the item hasn&rsquo;t aged past its interval since the
  last drop (or, for never-dropped items, since it was created).
- Skip if the next computed price would be below the minimum-price
  floor.
- Otherwise, post the new price.

At most one drop per item per run. An item that&rsquo;s been on for
60 days with a 14-day interval drops once on the next tick - it
doesn&rsquo;t catch up by firing 4 drops back-to-back.

## History

The tab shows the last 500 markdown attempts in a scrollable log:
which listing, which marketplace, the price before and after, and
whether the post succeeded. Useful for spotting items hitting their
floor or items where the post failed (rate-limited, item gone,
etc.).

You can clear the history at any time without affecting tracked
items.

## Stopping markdowns on an item

Click the item in the tracked grid and pick **Remove**. The next
scheduler tick won&rsquo;t touch it. Already-applied drops stay in
place - the listing just stops moving.

You can also stop everything at once with the master toggle.
