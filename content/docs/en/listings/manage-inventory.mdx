# Manage your inventory

The **Listings** tab merges your Depop and Vinted catalogue into one sortable
grid. Each row is one listing with a platform badge so you always know where
it lives. Filters, bulk edits, refresh, relist, price changes and delete all
work across both marketplaces from the same screen.

## What the grid shows

Per row, the grid shows:

- Photo, title and platform badge.
- Status (active, sold, draft, hidden).
- Price.
- Listed date and age.
- Restock toggle and quantity (when available).
- Quick-edit buttons.

Click any column header to sort. Click a row to expand the detail drawer with
the full description, all photos, tags and the edit form.

## Filtering and search

The toolbar above the grid has filters for:

- **Platform** &mdash; Depop only, Vinted only, or both.
- **Status** &mdash; active, sold, draft, hidden.
- **Marketplace search** &mdash; types into the source marketplace&rsquo;s
  search index. Useful when you remember a phrase from the title.

Filters stack: platform = Vinted + status = active + search = &ldquo;jeans&rdquo;
narrows the grid to just those rows.

## Bulk actions

Select multiple rows by clicking their checkboxes (or use the header checkbox
to select everything visible). The toolbar reveals bulk actions:

- **Refresh** &mdash; re-saves selected listings to push them up the search
  feed (Depop). See the [Listing refresher](/docs/visibility/listing-refresher) doc.
- **Relist** &mdash; deletes and re-creates each listing from scratch with
  optional photo modifications. See [Relister](/docs/sales/relister).
- **Price change** &mdash; flat percentage drop or fixed amount across
  selection.
- **Delete** &mdash; removes the listings from the marketplace. There is no
  undo.

## Quick edit

The pencil icon on any row opens an inline editor for title, description and
price. Save commits to the marketplace immediately. Useful for one-off typo
fixes without leaving the dashboard.

## Restocker columns

If a row supports restocking (active Vinted item, or a Depop item linked to a
Vinted item), the **Restock** toggle and **Qty** input appear in-row. See
[Restocker](/docs/sales/restocker) for the full flow.

## Encrypted cloud backup

On any paid plan, your listings index is encrypted and synced to your
SaleLinx account. That powers two things:

1. **Cross-device** &mdash; sign in on a different machine and your inventory
   shows up.
2. **Recovery** &mdash; the [Relister](/docs/sales/relister) can recreate
   listings from your backup, including photos, even if the marketplace
   removes the original.

Photos are stored on Supabase storage; titles and descriptions are encrypted
client-side before upload, so we never see them in plain text.

## Multi-language

The panel itself is available in English, French, Spanish and German with
light and dark themes. Listing data stays in whatever language you wrote it
in &mdash; SaleLinx never re-translates user content.
