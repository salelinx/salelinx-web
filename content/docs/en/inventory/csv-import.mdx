# CSV import

Bring an existing inventory in from another tool and post it to Depop
or Vinted as listings. SaleLinx works out the file format from the
column headers, so you don&rsquo;t need to map fields by hand for the
supported exports.

## When to use it

- Migrating from another reselling tool (e.g. dotb).
- Importing a Shopify product export.
- Re-loading a SaleLinx export after a wipe or platform switch.

If you only have a handful of items, the standard
[Crosslist](/docs/inventory/crosslist) flow is faster.

## Supported formats

SaleLinx checks the headers and shows the format it found in the
preview, for example **Format: Shopify**:

- **SaleLinx** - the file SaleLinx&rsquo;s own **Export All** creates.
  Recognised by its `platform`, `platform_id`, `title`, `price` and
  `photo_1` columns. Carries the title, description, brand, price,
  currency and photos.
- **dotb** - a Vinted-native export. Recognised by its `title`,
  `description`, `price` and `photo_1` columns, and shown as
  **Format: Vinted** in the preview. When you import it to Vinted it
  also carries the category, size, condition, parcel size, colours,
  brand and measurements, so it needs the least tidying up.
- **Shopify** - a product CSV from a Shopify store. Rows that share a
  handle become one item with all their images. The vendor becomes
  the brand, HTML is stripped from the description, and long titles
  are cut to 100 characters. Titles with seven or more capital
  letters are switched to lower case.

If none of these match, the preview says **Unrecognised CSV format**
and **Start Import** stays greyed out. You can skip detection by
choosing a format in the **Format** menu before you pick the file, but
the columns still need the names that format uses.

## Before you start

Have the marketplace you&rsquo;re importing to open in a tab and
signed in, with the same account you linked to SaleLinx. A Vinted
import stops straight away if no Vinted tab is open, and a Depop
import stops if you aren&rsquo;t logged into Depop.

## Importing

1. Open the **My Listings** tab.
2. Click the **CSV** button (the file icon) in the toolbar.
3. Under **Import**, leave **Format** on **Auto-detect** (or pick
   **SaleLinx**, **dotb** or **Shopify**) and click **Import CSV**.
4. Click **Choose CSV file (Vinted or Shopify format)** and pick your
   file. Any of the three formats above works here, up to 20 MB.
5. Check the preview: the detected format, how many items were found,
   and the first five rows with their title, price and image count.
6. Under **Target Platform**, pick **Vinted** or **Depop**.
7. Leave **Save as Draft** ticked (it is on by default) to create
   drafts you review on the marketplace before they go live. Untick
   it to publish straight away.
8. Click **Start Import**.

SaleLinx works through the file one item at a time with pauses
between photo uploads and listings, so the marketplace doesn&rsquo;t
see a sudden burst. The progress bar shows how many items were
created, failed and skipped. Click **Stop** to halt the import
part-way.

## What gets filled in

The marketplace still needs details that most exports don&rsquo;t
include, so expect to finish some listings by hand:

- **Vinted** - from a SaleLinx or Shopify file, the category, size
  and brand are left empty. Condition is set to **Good** and the
  parcel size to small when the file doesn&rsquo;t say.
- **Depop** - SaleLinx fills in the title, description, brand, price
  and photos. Category, size, condition and shipping are left for you
  to complete on Depop.

This is why **Save as Draft** is the safer choice for anything other
than a dotb file going to Vinted.

Check the currency in the preview too. Shopify files are always read
as euros, whatever your store uses.

## What rows are skipped

- Rows with no photo URLs are skipped and counted as skipped.
- Blank lines are ignored, and so are Shopify rows without a handle.

A photo that can&rsquo;t be downloaded is left out, and the item is
still created with the photos that did work, even if that is none.
If the marketplace turns an item down (for example because a
required detail is missing), it counts as failed and the import moves
on to the next row. One bad row never stops the rest.

## Exporting

The same **CSV** menu has an **Export All** button. It downloads
every listing in **My Listings**, from both marketplaces and in every
status, as a SaleLinx-format CSV. Use it as a backup, or to move an
inventory to a different SaleLinx account. To export only some
listings, select them and use **Export** in the toolbar (see
[Bulk editor](/docs/inventory/bulk-editor)).
