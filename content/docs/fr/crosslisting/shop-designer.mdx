# Shop Designer (Depop)

Shop Designer est un outil visuel de mise en page pour votre boutique Depop.
Il permet d'épingler, réorganiser et regrouper vos annonces actives sans
passer par l'interface de Depop, qui est laborieuse sur le web et lente sur
mobile.
