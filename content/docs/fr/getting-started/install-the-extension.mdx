# Installer l'extension SaleLinx

SaleLinx fonctionne entièrement dans votre navigateur. Installez-le une fois,
épinglez-le à votre barre d'outils et connectez-vous avec le compte que vous
utilisez pour la facturation.

Vous aurez besoin de Google Chrome ou d'un navigateur Chromium (Edge, Brave,
Arc) et d'un compte SaleLinx.

## 1. Installer depuis le Chrome Web Store

<InstallExtensionButton label="Ajouter à Chrome" className="my-6 inline-flex items-center gap-2 rounded-full bg-zinc-900 px-5 py-2.5 text-sm font-medium text-white shadow-[0_1px_0_rgba(255,255,255,0.08)_inset,0_10px_30px_-12px_rgba(0,0,0,0.45)] transition hover:bg-zinc-800 dark:bg-white dark:text-zinc-900 dark:hover:bg-zinc-100" />

Ou ouvrez la [fiche SaleLinx](https://chromewebstore.google.com/detail/salelinx/oichfmfogobecihmhlgkfcfbdceomenj) dans le Chrome Web Store et cliquez sur **Ajouter à
Chrome**. Chrome vous demandera de confirmer les permissions dont l'extension
a besoin. Cliquez sur **Ajouter l'extension** pour continuer.

<Callout variant="tip" title="Ce que signifient les permissions">
SaleLinx demande l'accès à depop.com et vinted.com pour pouvoir lire vos
propres annonces et remplir les formulaires en votre nom. L'extension ne
s'exécute sur aucun autre site.
</Callout>

## 2. Épingler l'extension

Après l'installation, Chrome masque les nouvelles extensions derrière l'icône
puzzle dans la barre d'outils. Épinglez SaleLinx pour y accéder en un clic.

<InstallPinCallout />

## 3. Se connecter

Cliquez sur l'icône SaleLinx épinglée pour ouvrir le panneau latéral.
Connectez-vous avec l'adresse e-mail et le mot de passe utilisés à
l'inscription sur salelinx.com. Si vous n'êtes pas encore inscrit, utilisez le
lien **Créer un compte** en bas du panneau.

<Callout>
La facturation et l'extension utilisent le même compte. Si vous réinitialisez
votre mot de passe sur le site, utilisez aussi le nouveau mot de passe ici.
</Callout>

## 4. Votre première utilisation

Rendez-vous sur [depop.com](https://www.depop.com) ou [vinted.com](https://www.vinted.com).
Le panneau SaleLinx s'ouvre automatiquement sur les pages produit et profil.
Vous verrez une courte liste pour lier vos comptes de marketplace, importer
vos annonces et lancer votre premier crosslisting.

## Dépannage

Si quelque chose ne va pas, la [FAQ](/faq#troubleshooting) propose des
solutions rapides aux problèmes d'installation les plus courants (panneau
qui n'apparaît pas, Chrome qui bloque l'installation, connexion sur le
mauvais compte).
