# La file d'attente

La plupart du travail que SaleLinx fait pour vous sur Depop et Vinted
passe par la file d'attente&nbsp;: Croissance, Rafraîchir, Republier,
Crosslist, Designer de boutique, Baisses de prix, Offres auto, l'import
CSV et les actions groupées de **Mes annonces**, comme la modification,
la suppression ou la publication de brouillons.

Chaque exécution attend son tour, et les requêtes qu'elle envoie sont
espacées comme celles d'une personne qui utilise le site. Les
marketplaces limitent la vitesse à laquelle un compte peut agir, et un
compte qui va plus vite peut être ralenti ou bloqué. La file d'attente
permet à SaleLinx de rester sous ces limites.

La file se trouve en bas de la barre latérale gauche du panneau, sous
**Paramètres**, et le bouton **See more...** ouvre la fenêtre complète.
Fermer le panneau ne change rien&nbsp;: la file continue en
arrière-plan. Tant qu'une tâche attend pour une marketplace, gardez au
moins un onglet de cette marketplace ouvert.
