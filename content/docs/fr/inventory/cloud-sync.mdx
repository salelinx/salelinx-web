# Synchronisation cloud

Par défaut, SaleLinx stocke vos annonces localement dans votre
navigateur. La synchronisation cloud, optionnelle et activable par
annonce, copie ces données (et les photos) sur votre compte
SaleLinx (Supabase). L'**enrichisseur** est le processus en
arrière-plan qui rend la synchro possible.
