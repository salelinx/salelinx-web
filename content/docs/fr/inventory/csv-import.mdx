# Import CSV

Importez un inventaire existant depuis un autre outil et publiez-le
sur Depop ou Vinted. SaleLinx auto-détecte le format du fichier
depuis les en-têtes des colonnes, donc pas besoin de mapper les
champs à la main pour les exports pris en charge (dotb, Shopify,
SaleLinx).

et les paliers d'abonnement.
