# Annonces

L'onglet **Annonces** fusionne votre catalogue Depop et Vinted dans
une grille triable. Chaque ligne est une annonce avec un badge de
plateforme. Filtres, modifications en masse, rafraîchissement,
republication, changements de prix et suppression fonctionnent sur
les deux marketplaces depuis le même écran.
