# Shop Designer

Shop Designer est un outil visuel de mise en page pour votre
boutique Depop. Il vous permet d'épingler, de réorganiser et de
grouper vos annonces actives sans glisser des éléments dans l'UI
de Depop, qui est fastidieuse sur le web et lente sur mobile.

Cette fonctionnalité est **Depop uniquement**.
