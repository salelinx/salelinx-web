# Crosslist

L'onglet Crosslist prend n'importe quelle annonce déjà créée sur une
marketplace et la publie sur l'autre. Tout le transfert se fait via
les API des marketplaces en arrière-plan. Pas de formulaire à
remplir, pas de nouvel onglet à surveiller, pas d'attente d'un
éditeur qui charge. Vous choisissez les articles, cliquez sur le
bouton, et regardez la file d'attente tourner.

<Callout>
Traduction française complète à venir. Voir la
[version anglaise](/en/docs/inventory/crosslist) pour le picker de
cartes, le bouton de direction (Depop↔Vinted), le filtre lié /

photos), les lots sans limite, et les paliers d'abonnement.
