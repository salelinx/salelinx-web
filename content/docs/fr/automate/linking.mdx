# Linking

L'onglet Linking associe une annonce Depop à son équivalent Vinted
pour que le reste de SaleLinx sache qu'elles sont le même article.
Un crosslist réussi définit le lien automatiquement&nbsp;; l'onglet
Linking est pour le cas où vous avez crosslisté manuellement en
dehors de SaleLinx ou perdu un lien.

l'unlinking et les paliers d'abonnement.
