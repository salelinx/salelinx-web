# Baisses de prix

L'onglet **Baisses de prix** réduit le prix des annonces que vous avez
choisi de suivre, selon un calendrier que vous fixez pour chaque
article. Il écoule le stock lent sans que vous ayez à y penser, et ne
descend jamais sous le prix plancher que vous choisissez.

Les baisses sont cumulatives, pas composées&nbsp;: chaque cycle retire
le même pourcentage du prix d'origine, jamais du prix actuel. Seules
les annonces actives sauvegardées dans le cloud peuvent être suivies
(voir [Synchronisation cloud](/docs/inventory/cloud-sync)), et la
fonctionnalité est réservée au forfait **Business**.
