# Shop Designer (Depop)

Shop Designer ist ein visuelles Layout-Tool für deinen Depop-Shop. Du kannst
deine aktiven Inserate anheften, neu sortieren und gruppieren, ohne dafür in
die Depop-Oberfläche zu gehen, die im Web umständlich und auf dem Handy
langsam ist.
