# Restocker

Der Restocker hält deinen Bestand zwischen den Marktplätzen ehrlich.
Zwei Szenarien:

1. **Mehrere Stück auf Vinted.** Du hast 3 gleiche T-Shirts. Stell
   **2 Restocks** ein: Bei jedem der ersten beiden Verkäufe stellt der
   Restocker eine frische Vinted-Anzeige für das nächste Stück ein.
   Der dritte Verkauf schließt den Artikel ab.
2. **Verknüpfte Artikel.** Derselbe Artikel ist auf Depop und Vinted
   eingestellt und [verknüpft](/docs/automate/linking). Beide Seiten
   teilen sich einen Bestand. Wenn das letzte Stück auf einer Seite
   verkauft wird, nimmt der Restocker die andere Seite offline, damit
   du nichts doppelt verkaufst.

Neu eingestellt werden nur Vinted-Anzeigen. Auf Depop schreibt
SaleLinx deinen Bestand stattdessen in Depops eigenes Mengenfeld, und
Depop hält die Anzeige online, bis sie ausverkauft ist. Ein Artikel
muss [in der Cloud gespeichert](/docs/inventory/cloud-sync) sein,
bevor der Restocker ihn verfolgen kann.
