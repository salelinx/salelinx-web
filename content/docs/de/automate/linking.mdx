# Linking

Der Linking-Tab verbindet ein Depop-Inserat mit seinem
Vinted-Gegenstück, damit der Rest von SaleLinx weiß, dass sie der
gleiche Artikel sind. Ein erfolgreicher Crosslist setzt die
Verknüpfung automatisch; der Linking-Tab ist für den Fall, dass
du außerhalb von SaleLinx manuell gecrosslistet oder eine
Verknüpfung verloren hast.
