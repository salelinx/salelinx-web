# Nachrichten

Der **Nachrichten**-Tab führt ungelesene Käufernachrichten von
Depop und Vinted in einer Zwei-Spalten-Ansicht zusammen. Jede Karte
zeigt das Käufer-Avatar, den Benutzernamen, die Zeit seit der
letzten Nachricht, eine zweizeilige Vorschau, das
Ungelesen-Abzeichen und ein Thumbnail des betroffenen Artikels.
