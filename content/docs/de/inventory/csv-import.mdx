# CSV-Import

Importiere einen vorhandenen Bestand aus einem anderen Tool und
veröffentliche ihn auf Depop oder Vinted. SaleLinx erkennt das
Dateiformat automatisch aus den Spaltenüberschriften, sodass du
für unterstützte Exports (dotb, Shopify, SaleLinx) keine Felder
manuell zuordnen musst.
