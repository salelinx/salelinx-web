# CSV-Import

Hol einen vorhandenen Bestand aus einem anderen Tool und stelle ihn als
Anzeigen auf Depop oder Vinted ein. SaleLinx erkennt das Dateiformat an
den Spaltenüberschriften, sodass du bei den unterstützten Exporten
(SaleLinx, dotb, Shopify) keine Felder von Hand zuordnen musst.

Den Import startest du im Tab **Meine Anzeigen** über den Button
**CSV** in der Toolbar. Dasselbe Menü hat auch **Alle exportieren**,
das alle deine Anzeigen als SaleLinx-CSV herunterlädt. Bei nur einer
Handvoll Artikel ist [Crosslist](/docs/inventory/crosslist) schneller.
