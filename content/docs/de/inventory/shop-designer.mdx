# Shop Designer

Shop Designer ist ein visuelles Layout-Tool für deinen Depop-Shop.
Es lässt dich aktive Inserate pinnen, umsortieren und gruppieren,
ohne Elemente in Depops eigener UI zu ziehen, die im Web fummelig
und auf dem Handy langsam ist.

Diese Funktion ist **nur Depop**.
