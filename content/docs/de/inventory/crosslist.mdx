# Crosslist

Der Crosslist-Tab nimmt jedes Inserat, das du auf einem Marktplatz
bereits erstellt hast, und legt auf dem anderen eine Kopie als Entwurf an. Die
gesamte Übertragung läuft im Hintergrund über die Marktplatz-APIs.
Kein auszufüllendes Formular, kein zu beobachtender neuer Tab, kein
Warten auf einen ladenden Editor. Du wählst die Artikel, klickst
den Button und schaust der Warteschlange beim Laufen zu.
