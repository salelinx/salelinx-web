# Cloud-Synchronisation

Standardmäßig speichert SaleLinx deine Inserate lokal in deinem
Browser. Die Cloud-Synchronisation ist optional und je Inserat
aktivierbar; sie kopiert diese Daten (und die Fotos) auf dein
SaleLinx-Konto bei Supabase. Die **Anreicherung** ist der
Hintergrundprozess, der die Synchronisation möglich macht.
